# Server

The server relays to that player's client. The notify provider draws it there.

```lua
Bridge.Notify(source, {
    title = 'Garage',
    description = 'Vehicle stored',
    kind = 'success',
    duration = 4000,
})
```

`kind` is `info`, `success`, `warning`, or `error`. Returns `true` when the client event is sent.

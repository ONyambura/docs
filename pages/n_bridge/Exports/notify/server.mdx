# Server

The server sends `n_bridge:notify` to that player's client. The notify provider draws it there.

### Notify

**Parameters**

- `source` `number` — server id
- `data` `table|string` — `{ title, description, kind, duration }`. `kind` is `info`, `success`, `warning`, or `error`.

**Returns**

`boolean` — `true` when the client event is sent.

**Example**

```lua
Bridge.Notify(source, {
    title = 'Garage',
    description = 'Vehicle stored',
    kind = 'success',
    duration = 4000,
})
```

# Server

Every server export. Topic pages above explain the payload. Calls that also exist on the client take a server id here.

## Player

| Export | Returns |
| --- | --- |
| `GetPlayer(source)` | `{ source, identifier, name, job, gang }` or `nil` |
| `GetPlayers()` | array of server ids |
| `GetIdentifier(source)` | character id, or `nil` |
| `GetPlayerJob(source)` | `{ name, grade, label, gradeLabel, onDuty }` |
| `GetPlayerGang(source)` | same shape. `name` is `none` when the framework has no gang |
| `GetPlayerMoney(source, account)` | number. `account` defaults to `cash`. `GetPlayerMoney(source, 500)` is not valid; pass the amount to add/remove |
| `AddPlayerMoney(source, account, amount)` | boolean. `AddPlayerMoney(source, 500)` adds cash |
| `RemovePlayerMoney(source, account, amount)` | boolean |
| `HasPermission(source, permission)` | boolean. `standalone` checks ACE |
| `OnPlayerReady(function(source) end)` | `true`. Players already loaded are passed in |
| `Notify(source, data)` | `true` when the client event is sent |

`data` for notify is `{ title, description, kind, duration }`. `kind` is `info`, `success`, `warning`, or `error`.

ESX maps `cash` to `money`. ox_core `cash` is the `money` item. ox_core `bank` is the character account.

## Inventory

| Export | Returns |
| --- | --- |
| `GetItemCount(source, item, metadata)` | number. `metadata` is optional |
| `HasItem(source, item, count, metadata)` | boolean. `count` defaults to `1` |
| `AddItem(source, item, count, metadata)` | boolean |
| `RemoveItem(source, item, count, metadata)` | boolean |
| `CanCarry(source, item, count, metadata)` | boolean |
| `GetItemLabel(item)` | string |
| `RegisterUsableItem(item, function(source, item) end)` | boolean |

`item` inside the usable callback is `{ name, count, metadata, slot }`.

ox_inventory only runs that callback for items the inventory already treats as usable. lj-inventory carry only checks that the player exists.

## Keys

| Export | Returns |
| --- | --- |
| `GiveKeys(source, plate, model)` | boolean |
| `RemoveKeys(source, plate, model)` | boolean |
| `HasKeys(source, plate)` | boolean |

`model` is only used by qs-vehiclekeys. qbx_vehiclekeys and p_vehiclekeys need that plate spawned. qs-vehiclekeys, MrNewbVehicleKeys, and p_vehiclekeys have no server key check, so `HasKeys` returns `false`.

n_carlock server order is source, then plate. wasabi_carlock uses its own `GiveKey(source, plate)` / `HasKey(source, plate)`.

## Phone

| Export | Returns |
| --- | --- |
| `SendPhoneNotification(source, data)` | boolean |
| `SendPhoneMail(source, data)` | boolean |

`data` is `{ sender, subject, message, address, title, description, app }`. sky_phone mail returns `false`.

## Dispatch

`SendDispatch(data)` returns boolean.

`data` is `{ source, code, title, message, coords, jobs, priority, blip }`. `jobs` is a string or an array. `blip` is `{ sprite, color, scale, length }`.

cd_dispatch, cd_dispatch3d, and ps-dispatch need `data.source`. The alert is filed from that player's client.

## Society

| Export | Returns |
| --- | --- |
| `GetSocietyMoney(job)` | number or `nil` |
| `AddSocietyMoney(job, amount)` | boolean |
| `RemoveSocietyMoney(job, amount)` | boolean |

`job` is the society name, such as `police`. esx_addonaccount stores it as `society_police`.

## Vehicles

`GetOwnedVehicles(source)` returns an array of `{ plate, model, garage, state }`, or `nil` when oxmysql or the identifier is missing.

`state` is `garaged`, `out`, or `impounded`. ESX `garage` is `nil`. ESX `model` is the hash stored in the vehicle JSON. QB and Qbox `model` is the `vehicle` column.

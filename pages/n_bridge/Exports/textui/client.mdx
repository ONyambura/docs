# Client

### ShowText

**Parameters**

- `text` `string`

**Returns**

`boolean`

**Example**

```lua
Bridge.ShowText('[E] Open the locker')
```

### HideText

**Parameters**

None.

**Returns**

`boolean`

**Example**

```lua
Bridge.ShowText('[E] Open the locker')
Wait(2000)
Bridge.HideText()
```

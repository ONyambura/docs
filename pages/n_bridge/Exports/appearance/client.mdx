# Client

`GetAppearance` reads the ped that is wearing the clothes. qb-clothing has no client read, so that call returns `nil`; the saved skin is `GetAppearance(source)` on the server. A shop id is optional and only used by op-clothing and rcore_clothing.

### GetAppearance

**Parameters**

None.

**Returns**

`table|nil`

**Example**

```lua
local appearance = Bridge.GetAppearance()

if appearance then
    print(json.encode(appearance))
end
```

### SetAppearance

**Parameters**

- `appearance` `table` — the table returned by `GetAppearance`

**Returns**

`boolean`

**Example**

```lua
local appearance = Bridge.GetAppearance()

if appearance then
    Bridge.SetAppearance(appearance)
end
```

### OpenAppearance

**Parameters**

- `shop` `string` — optional shop id for op-clothing and rcore_clothing. Omit it to open the wardrobe or changing room.

**Returns**

`boolean`

**Example**

```lua
Bridge.OpenAppearance()
Bridge.OpenAppearance('binco')
```

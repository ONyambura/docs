# Server

`job` is the society name, such as `police`. Pass that name, not a prefixed account id.

### GetSocietyMoney

**Parameters**

- `job` `string`

**Returns**

`number|nil` — `nil` when no society provider is selected.

**Example**

```lua
local balance = Bridge.GetSocietyMoney('police')
print(balance or 0)
```

### AddSocietyMoney

**Parameters**

- `job` `string`
- `amount` `number`
- `reason` `string` — optional. qb-banking stores it. Other society scripts ignore it.

**Returns**

`boolean`

**Example**

```lua
if Bridge.AddSocietyMoney('police', 500, 'fine') then
    print(Bridge.GetSocietyMoney('police'))
end
```

### RemoveSocietyMoney

**Parameters**

- `job` `string`
- `amount` `number`
- `reason` `string` — optional. Same rule as add.

**Returns**

`boolean`

**Example**

```lua
if not Bridge.RemoveSocietyMoney('police', 100, 'payroll') then
    return
end
```

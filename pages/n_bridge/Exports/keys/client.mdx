# Client

A plate, for the local player. No server id.

qb-vehiclekeys, qbx_vehiclekeys, and t1ger_keys cannot remove a key from the client. Use the server call, except on t1ger_keys, which has no remove. qs-vehiclekeys, MrNewbVehicleKeys, p_vehiclekeys, okokGarage, and t1ger_keys return `false` from `HasKeys`. `ToggleLock` is n_carlock.

### GiveKeys

**Parameters**

- `plate` `string`
- `extra` `number` — optional. n_carlock treats this as the server id who should receive the key. qs-vehiclekeys, qbx_vehiclekeys, and p_vehiclekeys treat a vehicle entity here and search for the plate when it is omitted. qbx and p_vehiclekeys need a networked entity.

**Returns**

`boolean`

**Example**

```lua
Bridge.GiveKeys('44WSX569')
Bridge.GiveKeys('44WSX569', target)
```

### RemoveKeys

**Parameters**

- `plate` `string`
- `extra` `number` — optional, same meaning as `GiveKeys`

**Returns**

`boolean`

**Example**

```lua
Bridge.RemoveKeys('44WSX569')
```

### HasKeys

**Parameters**

- `plate` `string`

**Returns**

`boolean`

**Example**

```lua
if Bridge.HasKeys('44WSX569') then
    Bridge.ToggleLock()
end
```

### ToggleLock

n_carlock only. Other key scripts log once and do nothing.

**Parameters**

None.

**Returns**

`boolean`

**Example**

```lua
if Bridge.HasKeys('44WSX569') then
    Bridge.ToggleLock()
end
```

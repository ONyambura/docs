## Streamer Mode

### GetStreamerModeActive

Returns the `state` status for steamer mode

```lua
exports.n_pause:GetStreamerModeActive()
```

**Parameters**

- none

**Returns**

- `true / false`


### ToggleStreamerMode

Toggles the `state` status for steamer mode

```lua
exports.n_pause:ToggleStreamerMode()
```

**Parameters**

- none

**Returns**

- none

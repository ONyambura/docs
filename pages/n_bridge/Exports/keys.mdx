# Keys

Server calls take a server id, then a plate. Client calls take a plate and apply to the local player.

n_carlock and wasabi_carlock are separate providers. n_carlock server is `GiveKeys(source, plate)` and client is `GiveKeys(plate, target)`. wasabi_carlock server is `GiveKey(source, plate)` and client is `GiveKey(plate)`.

## Server

```lua
Bridge.GiveKeys(source, plate)
Bridge.RemoveKeys(source, plate)
Bridge.HasKeys(source, plate)
Bridge.GiveKeys(source, plate, 'ADDER')
```

Returns `true` or `false`. The model string is only used by qs-vehiclekeys. qbx_vehiclekeys and p_vehiclekeys need that plate spawned. qs-vehiclekeys, MrNewbVehicleKeys, and p_vehiclekeys return `false` from `HasKeys`.

## Client

```lua
Bridge.GiveKeys(plate)
Bridge.RemoveKeys(plate)
Bridge.HasKeys(plate)
Bridge.ToggleLock()
```

n_carlock accepts a server id as the second argument, the player who should receive or lose the key.

```lua
Bridge.GiveKeys(plate, target)
```

qs-vehiclekeys, qbx_vehiclekeys, and p_vehiclekeys accept a vehicle entity instead, and search for the plate when it is omitted. The entity must be networked for qbx and p_vehiclekeys.

qb-vehiclekeys and qbx_vehiclekeys cannot remove a key from the client. Use the server call. `ToggleLock` is implemented by n_carlock.

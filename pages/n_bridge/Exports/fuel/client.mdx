# Client

### GetFuel

**Parameters**

- `vehicle` `number` — vehicle entity

**Returns**

`number`

**Example**

```lua
local amount = Bridge.GetFuel(vehicle)
print(amount)
```

### SetFuel

**Parameters**

- `vehicle` `number` — vehicle entity
- `amount` `number` — `0.0` to `100.0`

**Returns**

`boolean`

**Example**

```lua
local amount = Bridge.GetFuel(vehicle)

if amount < 20.0 then
    Bridge.SetFuel(vehicle, 80.0)
end
```

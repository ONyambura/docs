# Server

Needs `oxmysql`.

```lua
local vehicles = Bridge.GetOwnedVehicles(source)
```

Returns a list, or `nil` when the player or the database is missing:

```lua
{
    plate = '44WSX569',
    model = 'adder',
    garage = 'pillboxgarage',
    state = 'garaged', -- garaged | out | impounded
}
```

ESX reads `owned_vehicles`. QB and Qbox read `player_vehicles`. `garage` is `nil` on ESX. ESX `model` is the hash stored in the vehicle JSON.

# Server

`job` is the society name, such as `police`. ESX accounts use the `society_` prefix internally.

### GetSocietyMoney

**Parameters**

- `job` `string`

**Returns**

`number|nil` — `nil` when no society provider is selected.

**Example**

```lua
local balance = Bridge.GetSocietyMoney('police')
print(balance or 0)
```

### AddSocietyMoney

**Parameters**

- `job` `string`
- `amount` `number`

**Returns**

`boolean`

**Example**

```lua
if Bridge.AddSocietyMoney('police', 500) then
    print(Bridge.GetSocietyMoney('police'))
end
```

### RemoveSocietyMoney

**Parameters**

- `job` `string`
- `amount` `number`

**Returns**

`boolean`

**Example**

```lua
if not Bridge.RemoveSocietyMoney('police', 100) then
    return
end
```

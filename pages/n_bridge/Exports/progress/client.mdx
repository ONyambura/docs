# Client

Qbox progress expects `ox_lib`.

### Progress

**Parameters**

- `data` `table`
- `duration` `number` — milliseconds. Defaults to `1000`.
- `label` `string`
- `canCancel` `boolean` — defaults to `true`
- `anim` `table` — `{ dict, clip }`
- `disable` `table` — `{ move, car, combat, mouse }`

**Returns**

`boolean` — `true` when the bar finishes. `false` when it is cancelled or no progress provider is selected.

**Example**

```lua
local finished = Bridge.Progress({
    duration = 5000,
    label = 'Searching',
    canCancel = true,
    anim = { dict = 'anim@amb@clubhouse@tutorial@bkr_tut_ig3@', clip = 'machinic_loop_mechandplayer' },
    disable = { move = true, car = true, combat = true, mouse = false },
})

if not finished then
    return
end

Bridge.Notify({ description = 'Search finished', kind = 'success' })
```

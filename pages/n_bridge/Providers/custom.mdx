# Custom provider

`providers/<capability>/custom` stays readable after escrow. `auto` never selects `custom`. Set `Config.Use.<capability> = 'custom'`. An id that is not in the catalog falls through to `custom` as well.

Each capability has `client.lua`, `server.lua`, or both. The file returns unless that id is selected, then hands its methods to `Bridge.Provide`. `core/bind.lua` publishes the public names, so the provider leaves `exports()` out.

```lua
if Bridge.Selected('framework') ~= 'custom' then return end

Bridge.Provide('framework', 'custom', {
    getMoney = function(source, account)
        return MyFramework.GetMoney(source, account or 'cash')
    end,

    addMoney = function(source, account, amount, reason)
        account, amount, reason = Bridge.MoneyArgs(account, amount, reason)
        return MyFramework.AddMoney(source, account, amount, Bridge.MoneyReason(reason)) == true
    end,
})
```

Keep every method that is already in the file. A missing method logs once and the call returns `nil`. The stubs already return the empty value for each signature (`0`, `false`, `{}`, or `nil`), so fill the ones your script can do and leave the rest.

Client methods describe the local player and take no server id. Where the same call exists on the server, `source` is the first argument.

Call this when the character finishes loading. Listeners that were registered earlier run immediately if the character is already loaded.

```lua
Bridge.RaisePlayerReady(source) -- server
Bridge.RaisePlayerReady()       -- client
```

Zones, health, armor, callbacks, and `CheckVersion` live in the core. They have no custom folder.

## Helpers

Build return values with these so they match the shipped backends.

| Helper | Result |
| --- | --- |
| `Bridge.Player(source, identifier, name, job, gang)` | `{ source, identifier, name, job, gang }` |
| `Bridge.Job(name, grade, label, onDuty, gradeLabel)` | `{ name, grade, label, gradeLabel, onDuty }`. Empty args are unemployed and on duty. A gang with no membership is `Bridge.Job('none', 0, 'none', false)`. |
| `Bridge.Character(firstName, lastName, phone, gender, dateOfBirth)` | `{ firstName, lastName, phone, gender, dateOfBirth }` |
| `Bridge.MoneyArgs(account, amount, reason)` | Account name, amount, reason. A bare number is treated as a cash amount. |
| `Bridge.MoneyReason(reason)` | The reason, or `n_bridge` when it was omitted. |
| `Bridge.MatchesGroup(groups, identifier, filter)` | `groups` is `{ [name] = grade }`. `filter` is a name, a list of names, or `{ name = minGrade }`. |
| `Bridge.JobCatalog(raw)` | `{ { name, label, grades = { { grade, name, label, isBoss } } } }` |
| `Bridge.ItemContext(name, count, metadata, slot)` | `{ name, count, metadata, slot }` |
| `Bridge.ItemRows(entries)` | Item rows from a slot table. Reads `count` or `amount`, and `metadata` or `info`. |
| `Bridge.CountNamedItems(entries, item, metadata)` | Combined count. Metadata is matched with `Bridge.MetadataMatches`. |
| `Bridge.SlotWithItem(entries, item, metadata)` | One `ItemContext`, or `nil`. |
| `Bridge.NotifyParts(data)` | `title, message, kind, duration, text`. `kind` is `info`, `success`, `warning`, or `error`. |
| `Bridge.ProgressData(data)` | `{ duration, label, canCancel, anim, disable }` |
| `Bridge.DispatchData(data)` | Normalized alert, including `jobs` and `blip`. On the server, `Bridge.FillDispatchCoords(data)` fills coords from `data.source`. |
| `Bridge.PhoneNote(data)` | `{ sender, from, subject, message, address, title, description, app }` |
| `Bridge.InputFields(fields)` | One field shape: `{ type, label, name, default, required, options, min, max, placeholder }` |
| `Bridge.InputResult(fields, values)` | Values by position and by `name`, or `nil` when `values` is not a table. |
| `Bridge.MenuData(data)` | `{ id, title, options }`. Each option is `{ title, description, icon, disabled, arrow, onSelect, args }`. |
| `Bridge.Percent(value)` | The value clamped to `0`–`100`, or `nil` when it is not a number. |

`RegisterUsableItem` calls the inventory method `registerUsable`. That method may call `Bridge.Call('framework', 'registerUsable', item, handler)` when the framework owns usable items. The framework method must not call the inventory method back. `handler(source, item)` receives an `ItemContext`.

## Notify, progress, text UI, target

These are client files. Server `Notify(target, data)` relays to that player's client, so a custom notify only implements `push`.

```lua
push = function(data)
    local title, message, kind, duration = Bridge.NotifyParts(data)
end
```

| Call | Method | Returns |
| --- | --- | --- |
| `Notify(data)` | `push` | nothing. `data` is `{ title, description, kind, duration }` or a string. The shipped stub prints it with the feed ticker. |
| `Progress(data)` | `start` | `true` when the bar finishes, `false` when it is cancelled. Use `Bridge.ProgressData`. `disable` keys are `move`, `car`, `mouse`, `combat`. |
| `ShowText(text)` | `show` | nothing |
| `HideText()` | `hide` | nothing |
| `AddEntityTarget(entity, options)` | `addEntity` | an id the matching `remove` understands |
| `AddModelTarget(models, options)` | `addModel` | an id |
| `AddBoxZone(data)` | `addBox` | an id. `data` is `{ id, coords, size, rotation, options }`. |
| `RemoveTarget(id)` | `remove` | `boolean` |

Each target option is `{ name, label, icon, distance, onSelect, canInteract }`.

## Input and menu

```lua
open = function(title, fields)
    fields = Bridge.InputFields(fields)
    local values = MyUi.Ask(title, fields) -- nil when the player cancels
    return Bridge.InputResult(fields, values)
end
```

`type` is `text`, `password`, `number`, `checkbox`, `select`, `textarea`, `slider`, `color`, or `date`. `options` is `{ { value, label } }`.

| Call | Method | Returns |
| --- | --- | --- |
| `InputDialog(title, fields)` | `open` | `Bridge.InputResult`, or `nil` |
| `OpenMenu(data)` | `open` | menu id. Read the menu from `Bridge.MenuData(data)` and call each option's `onSelect(args)`. |
| `CloseMenu()` | `close` | `boolean` |

## Status

Values are `0` to `100`. Clamp with `Bridge.Percent`.

| Call | Method | Returns |
| --- | --- | --- |
| `GetPlayerStatus(source, name)` | `get` | `number`, or `nil`. The client method is `get(name)`. |
| `SetPlayerStatus(source, name, value)` | `set` | `boolean` |
| `AddPlayerStatus` / `RemovePlayerStatus` | `add(source, name, amount)` | `boolean`. Optional. `amount` is negative for a remove. With no `add` method, the bridge reads the value and calls `set`. |

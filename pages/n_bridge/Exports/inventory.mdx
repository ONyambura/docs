# Inventory

Server calls take a server id. Client calls read the local player and do not.

## Server

```lua
Bridge.GetItemCount(source, 'water', metadata)
Bridge.HasItem(source, 'water', 1, metadata)
Bridge.AddItem(source, 'water', 2, metadata)
Bridge.RemoveItem(source, 'water', 1, metadata)
Bridge.CanCarry(source, 'water', 2, metadata)
Bridge.GetItemLabel('water')
```

`metadata` is optional. Add, remove, carry, and has return booleans. Count returns a number. Label returns a string.

```lua
Bridge.RegisterUsableItem('radio', function(source, item)
    -- item = { name, count, metadata, slot }
end)
```

ox_inventory only runs that callback for items the inventory already treats as usable.

## Client

```lua
Bridge.GetItemCount('water', metadata)
Bridge.HasItem('water', 1, metadata)
Bridge.GetItemLabel('water')
local items = Bridge.GetPlayerItems()
local weapon = Bridge.GetCurrentWeapon()
Bridge.OpenInventory('stash', { id = 'locker', owner = 'police' })
```

Each row from `GetPlayerItems` is `{ name, count, metadata, slot, label }`. `GetCurrentWeapon` returns one row, or `nil`.

`OpenInventory` kinds are `stash`, `player`, and `shop`. ESX and chezza return `false`. jaksam returns `false` for another player. Adding and removing items stays on the server.

# Client

Owned-vehicle rows are read on the server through `oxmysql`.

### GetOwnedVehicles

Call this from the server.

**Parameters**

- `source` `number`

**Returns**

Nothing on the client. The server call returns a list of `{ plate, model, garage, state }`, or `nil`.

**Example**

```lua
-- server.lua
local vehicles = Bridge.GetOwnedVehicles(source)

if vehicles and vehicles[1] then
    Bridge.GiveKeys(source, vehicles[1].plate)
end
```

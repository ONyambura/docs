# Server

Reads the skin and outfits the selected clothing script stores. illenium-appearance, qb-clothing, fivem-appearance, and the rcore_clothing outfit list need `oxmysql`. Nothing is written to the database.

### GetAppearance

**Parameters**

- `source` `number` — server id

**Returns**

`table|nil` — the saved skin. When the player has no saved skin, the bridge returns what their ped is wearing as `{ model, components, props }`. `nil` only when the player has no ped.

**Example**

```lua
local appearance = Bridge.GetAppearance(source)

if appearance then
    print(appearance.model)
end
```

### GetOutfits

**Parameters**

- `source` `number` — server id

**Returns**

`table` — saved outfits. Empty when the player has none.

illenium-appearance and fivem-appearance rows are `{ id, name, model, components, props }`. qb-clothing rows are `{ id, name, model, skin }`. op-clothing and rcore_clothing return the rows those scripts store.

**Example**

```lua
local outfits = Bridge.GetOutfits(source)

for i = 1, #outfits do
    print(outfits[i].name)
end
```

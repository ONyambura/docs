# Custom provider

`providers/<capability>/custom` stays readable after escrow. Set the matching `Config.Use` key to `custom`.

```lua
if Bridge.Selected('framework') ~= 'custom' then return end

Bridge.Provide('framework', 'custom', {
    getMoney = function(source, account)
        return 0
    end,
})
```

The public export is registered by `core/bind.lua`. Do not call `exports()` inside the provider.

When the character is ready:

```lua
-- server
Bridge.RaisePlayerReady(source)

-- client
Bridge.RaisePlayerReady()
```

Build return values with `Bridge.Player`, `Bridge.Job`, `Bridge.MoneyArgs`, and `Bridge.ItemContext` so they match the shipped backends.

Framework server: `getPlayer`, `getPlayers`, `getIdentifier`, `getJob`, `setJob`, `getGang`, `setGang`, `setDuty`, `getMoney`, `addMoney(source, account, amount, reason)`, `removeMoney`, `setMoney`, `getMetadata`, `setMetadata`, `getByIdentifier`, `getByPhone`, `getPlayersByJob`, `getDutyCount`, `hasPermission`, `registerUsable`. `Bridge.MoneyReason(reason)` fills a missing reason with `n_bridge`.

Framework client: `getPlayerData`, `isLoaded`, `getIdentifier`, `getJob`, `getGang`, `getMoney`, `getMetadata`. Public names are `GetPlayerData`, `IsPlayerLoaded`, `GetIdentifier`, `GetPlayerJob`, `GetPlayerGang`, `GetPlayerMoney`, and `GetPlayerMetadata`. Client methods take no server id.

Inventory server: `getCount(source, item, metadata)`, `hasItem`, `addItem`, `removeItem`, `canCarry`, `getLabel`, `registerUsable`.

Inventory client: `getCount(item, metadata)`, `hasItem`, `getLabel`, `getItems`, `getWeapon`, `openInventory`.

`registerUsable` may call `Bridge.Call('framework', 'registerUsable', item, handler)`. The framework method must not call the inventory method back.

Notify: `push(data)`. Target: `addEntity`, `addModel`, `addBox`, `remove`. Progress: `start(data)` returns `true` or `false`.

Appearance: `getAppearance`, `setAppearance(appearance)`, `openAppearance(shopId)`.

Fuel: `getFuel(vehicle)`, `setFuel(vehicle, amount)`.

Keys server: `giveKeys(source, plate, model)`, `removeKeys(source, plate, model)`, `hasKeys(source, plate)`.

Keys client: `giveKeys(plate, extra)`, `removeKeys(plate, extra)`, `hasKeys(plate)`, `toggleLock()`.

Boss menu: `open()`.

Phone: `sendMail(source, data)`, `sendNotification(source, data)`.

Dispatch: `send(data)`.

# Updates

## 0.8.0

`GetCharacter` returns first name, last name, phone, gender, and date of birth. Phone is missing on ox and ND. `IsBoss` is false on ND and vRP. `HasGroup` accepts a name, a list, or a minimum grade. `GetJobs` and `GetGangs` list what that framework has registered. ESX, ND, and vRP have no gang list.

`RegisterCallback` and `TriggerCallback` are the bridge's own callbacks. The server can also ask one player's client with `TriggerClientCallback` or `AwaitClientCallback`, answered by `RegisterClientCallback`. Client helpers cover the closest player, ped, vehicle, and object, plus spawn, delete, and plate. `GetVehicleProperties` and `SetVehicleProperties` use that framework's property table. Qbox, ox, and ND need ox_lib for properties.

`GetSlotWithItem` works on the server as well as the client.

Server `GetAppearance` and `GetOutfits` read the saved skin and outfit list from each clothing script's own tables or exports. With no saved skin, `GetAppearance` asks that player's client what the ped is wearing. Client `SetSkin` and `GetSkin` use one component and prop format for every clothing script, and can dress a ped another client owns. qb-clothing's client `GetAppearance` now reads the ped instead of returning nothing.

Phone calls on the server look up a player's number or the player behind a number, send a text, and check or end a call. The client can open, close, and disable the phone and show a notification. 17mov_Phone is a phone provider.

## 0.7.0

Cash and bank add, remove, and set take an optional reason. When the caller omits it, the bridge sends `n_bridge`. vRP accepts the argument and ignores it. Society add and remove take the same reason, and only qb-banking stores it.

`GetPlayerByPhone` returns a server id. ESX, ox, ND, and vRP return `nil`. `GetDutyCount` returns how many players are on duty for a job. ND has no duty flag, so that count is everyone with the job.

Export pages list parameters, the return value, and one example. Confiscate and return inventory are not bridge calls.

## 0.6.0

Player calls now cover job, gang, duty, metadata, exact money, and lookup by identifier, using the ESX, QBCore, Qbox, ox_core, and ND Core functions those projects document. Every export page is one function, then parameters, the return value, and an example.

## 0.5.0

Inventory exports cover slots, metadata, durability, weight, stashes, and usable items. Other inventories implement the calls they already provide. ESX default items and chezza have no metadata.

## 0.4.0

Client inventory, keys, gang, identifier, and boss menu. Each export group opens into Client and Server.

n_carlock and wasabi_carlock are separate providers. ps-inventory, lj-inventory, illenium-appearance, fivem-appearance, each fuel script, cd_dispatch, cd_dispatch3d, ps-dispatch, and Qbox vehicles are separate files too.

Client calls do not take a server id. `GiveKeys(plate)` is local. `GiveKeys(source, plate)` stays on the server. `ToggleLock` is n_carlock.

## 0.3.0

Client player calls use the usual names. `GetPlayerData`, `GetPlayerJob`, and `GetPlayerMoney` describe the local player and do not take a server id. Server `GetPlayerJob` and `GetPlayerMoney` still take a server id.

Exports in the docs are grouped by topic.

- Society: Renewed-Banking, okokBanking, qb-banking, qb-management, esx_addonaccount
- Owned vehicles: QB, Qbox, ESX
- Text UI: ox_lib, okokTextUI, qb-core
- Fuel: cdn-fuel, qs-fuelstations, Renewed-Fuel, okokGasStation, x-fuel
- Keys: Renewed-Vehiclekeys, MrNewbVehicleKeys

# Server

A server id, then a plate. qbx_vehiclekeys, p_vehiclekeys, mk_vehiclekeys, and mVehicle need that plate spawned. qs-vehiclekeys, MrNewbVehicleKeys, p_vehiclekeys, okokGarage, and t1ger_keys return `false` from `HasKeys`. t1ger_keys also returns `false` from `RemoveKeys`. cd_garage and F_RealCarKeysSystem ask that player's client, so `HasKeys` yields for up to 5 seconds.

### GiveKeys

**Parameters**

- `source` `number` — server id
- `plate` `string`
- `model` `string` — optional. Only qs-vehiclekeys uses it.

**Returns**

`boolean`

**Example**

```lua
Bridge.GiveKeys(source, '44WSX569')
Bridge.GiveKeys(source, '44WSX569', 'ADDER')
```

### RemoveKeys

**Parameters**

- `source` `number`
- `plate` `string`
- `model` `string` — optional, qs-vehiclekeys only

**Returns**

`boolean`

**Example**

```lua
Bridge.RemoveKeys(source, '44WSX569')
```

### HasKeys

**Parameters**

- `source` `number`
- `plate` `string`

**Returns**

`boolean`

**Example**

```lua
if Bridge.HasKeys(source, '44WSX569') then
    Bridge.Notify(source, { description = 'You have the keys', kind = 'success' })
end
```
